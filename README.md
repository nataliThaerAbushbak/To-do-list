# Java To-Do List

This project is a simple Java-based to-do list application developed to demonstrate basic object-oriented programming concepts and the implementation of a custom linked list data structure.

The application allows tasks to be added, searched by ID, updated by completion status, displayed according to completion state, and deleted from the list.

## Concepts Demonstrated

- Object-oriented programming
- Classes and objects
- Generic classes
- Custom linked list implementation
- Task identification using IDs
- Basic data management operations

## How to Run

1. Download or clone the repository.
2. Open the project in a Java IDE.
3. Run `ToDoListDemo.java`.
